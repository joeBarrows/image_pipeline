
#Pexel Image Query and S3 Upload Service
##Overview
This service provides a streamlined solution for querying Pexel's image API, applying custom filters, and uploading selected images along with their metadata to Amazon S3.
##Features
-Pexel Image Search: Query Pexel's API with customizable search parameters
-Image Filtering: Apply advanced filters to refine image selection
-S3 Upload: Automatically upload selected images and their metadata to an S3 bucket
-Metadata Extraction: Capture and store comprehensive image metadata
